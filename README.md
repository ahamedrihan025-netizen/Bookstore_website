# Bookstore_website
Simple Bookstore Website

A simple and beginner-friendly bookstore website developed as my first-semester project. The website provides a basic online bookstore interface where users can browse books and explore different sections of the store.

This project was created to practice fundamental web development concepts, including HTML, CSS, and JavaScript, while learning how to design and build a functional website from scratch.

Features

📚 Browse available books

🔍 Simple and user-friendly interface

🛒 Basic bookstore layout

📱 Responsive design

🎨 Clean and simple UI

This project represents one of my first steps into web development and helped me build a foundation in creating and designing websites.
